OpsTide is starting in {{ .Release.Namespace }}. It reads {{ if .Values.namespaces }}{{ join ", " .Values.namespaces }}{{ else }}the whole cluster{{ end }} and never writes to it.

Open it:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "opstide.fullname" . }} 8080:{{ .Values.service.port }}
  open http://127.0.0.1:8080

{{- if .Values.auth.enabled }}

OpsTide asks for a token. Read it:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "opstide.authSecretName" . }} -o jsonpath='{.data.token}' | base64 -d; echo
{{- end }}
